# Phase C6 — Источники исторического контента

## Происхождение контента

Все тексты карточек написаны редакторски (оригинальные русские тексты
SmartNavigator) на основе проверенных источников. Никакой контент не
скопирован дословно и не сгенерирован «по памяти» без сверки: для каждой
карточки выполнена сверка фактов с конкретной статьёй.

## Использованные источники

1. **Русскоязычная Википедия** — вспомогательный источник (приоритет 6 по §5.1
   ТЗ). Для каждой из 35 карточек статья была открыта и сверена
   2026-10-11; URL, дата доступа и лицензия (CC BY-SA 4.0) записаны в поле
   `sources` карточки. Спорные утверждения отбрасывались: если статья не
   подтверждала запрошенный факт (например, «первый буддийский храм Северной
   Европы» для дацана, «каменный футляр Растрелли» для Домика Петра I,
   даты постройки для музея Фаберже), факт в карточку не включался.
2. **Официальные сайты объектов** — из проверенного каталога Phase B
   (`official_website` в `seed_places.json`, происхождение — OSM-теги,
   зафиксировано в `docs/osm_source_snapshot.json`). Цитируются только там,
   где подтверждают конкретное утверждение карточки (например, статус здания
   как комплекса Эрмитажа). Главная страница сайта сама по себе не считается
   доказательством произвольных исторических заявлений.
3. **Независимые источники второго контура** (итерация ревью 2026-10-11) —
   у каждой из 35 карточек есть минимум два источника: помимо статьи
   Википедии подключён независимый ресурс более высокого приоритета —
   официальные сайты музеев и организаций (rusmuseum.ru, spbmuseum.ru,
   cathedral.ru, mariinsky.ru, alexandrinsky.ru, hermitagemuseum.org,
   yusupov-palace.ru, kazansky-spb.ru, theatremuseum.ru, gmgs.ru,
   navalmuseum.ru, elaginpark.org, dum-spb.ru, dazanspb.ru, igardens.ru,
   ipm.ru, binran.ru, newhollandsp.ru, pmemorial.ru, sevcableport.ru),
   государственные ресурсы (spbcult.ru, ar.culture.ru, visit-petersburg.ru,
   prlib.ru, academtalant.ru, iacis.ru) и научные публикации в журналах
   («Вопросы музеологии» о Кунсткамере, «Полярные чтения» о ледоколе
   «Красин»). Каждый URL был открыт и проверен: источник привязан только
   к тем элементам карточки, чьи утверждения он подтверждает дословно; где
   независимый источник расходится с Википедией (число захоронённых
   на Пискарёвском кладбище), противоречие зафиксировано в тексте карточки,
   а не замалчивается.

## Что сознательно исключено

- OpenStreetMap — не используется как подтверждение дат, авторства, событий
  или легенд (§5.1 ТЗ).
- Автоматически сгенерированные ИИ-ответы — не источник.
- Городские легенды не подаются как исторические события. Если предание
  упомянуто (видение архангела солдату перед строительством Михайловского
  замка), оно явно помечено как предание.
- Чужие тексты и изображения не копируются; карточки не содержат
  изображений вовсе (существующий `photo_url` каталога не менялся).

## Редакторская дисциплина дат

- Разделены основание, строительство и открытие (например, Смольный собор:
  закладка 1748 — освящение 1835).
- Не приписан современный облик одному периоду, если объект перестраивался
  (Юсуповский дворец: Валлен-Деламот 1770-е + Михайлов 1830-е + реставрации
  1890-х).
- Учтены переименования (Императорский фарфоровый завод → ЛФЗ → снова
  Императорский).
- Фиксированы противоречия источников: если авторство неизвестно
  (Каменноостровский дворец, Сампсониевский собор), это сказано прямо.
- При подключении независимых источников несколько утверждений, опиравшихся
  только на Википедию, были уточнены по первоисточникам: закладка
  Михайловского замка (не «через несколько дней после восшествия», а
  указ в первый месяц царствования, камень — 26 февраля 1797 года),
  валькирии Дома Зингера (одна держит швейную машинку, а не «у ног лежат»),
  формулировка Монферрана (не «в день освящения», а «после освящения»).

## Лицензионные обязательства

- Тексты карточек — оригинальные редакторские тексты SmartNavigator.
- Факты, почерпнутые из Википедии, сопровождаются ссылкой на статью
  (CC BY-SA 4.0) в разделе «Источники» пользовательского интерфейса.
- Официальные сайты указаны как источники музеев/учреждений.
- Ссылки на независимые источники не копируют их тексты: в карточках
  записаны только проверочные сведения (даты, атрибуции) и краткие
  пересказы, необходимые для подтверждения факта.

## Проверка

Скрипт `python -m app.db.validate_place_history` печатает список источников
каждой карточки и отклоняет набор при нарушении схем URL, дат и ссылочной
целостности. Те же правила выполняются в backend-тестах
(`tests/test_place_history.py`).
