# Phase C2 source and publication supplement

Reviewed 10 October 2026. This supplements, and does not overwrite,
`PHASE_B_SOURCE_LICENSES.md`. It records the project's conservative implementation
decision and the remaining publication work.

© OpenStreetMap contributors. The **complete 126-record catalog**, original
editorial additions, selected factual snapshots, raw OSM acquisition responses,
boundary evidence, district assignments and factual audit exports accompany the
[catalog notice](../app/db/README.md) under
[ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/).
Preserve the notice and [OSM copyright link](https://www.openstreetmap.org/copyright)
with copies. Original Russian editorial contents retain the express reuse
permission in that notice. No third-party prose or photographs were imported.

The adapted OSM catalog continues to be treated as a derivative database; no
claim that its size exempts it from share-alike/source-offer obligations is made.
The source package now requires `seed_places.json`, the adjacent notice, both
unchanged Phase B and additive Phase C2 selected snapshots/boundaries, current
object checks, acquisition request/hash evidence, and the manifests identifying
the complete database. Coordinate evidence must retain the July 24 mirror
timestamp separately from the October 10 current-object/tag checks. A parent
version check does not establish current way/relation geometry or public access.
OSM data redistribution needs readable credit and licence information; preserve
the existing map-adjacent attribution and source dialog according to the
[OSMF attribution guidelines](https://osmfoundation.org/wiki/Licence/Attribution_Guidelines).

**Before public distribution/use**, publish a versioned, freely downloadable
machine-readable complete derivative database or legally sufficient complete
alterations through an explicitly authorized publication channel, and add its
verified stable URL to the app's source information. The private GitHub branch
and an inaccessible raw URL do not complete the ODbL offer. Repository visibility
and hosting were not changed. The complete catalog offer must include all 126
records and applicable notices, rather than only the 49 additions.

Current [Overpass instance information](https://wiki.openstreetmap.org/wiki/Overpass_API)
was checked before acquisition. Bounded development-only requests and exact
successful raw evidence are documented in the C2 catalog audit; endpoint failures
and stale mirror data are retained as limitations. Official OSM API checks are
low-volume selected-object/boundary requests. There is no live harvesting in the
application and no runtime public Overpass dependency.

Yandex SDK tiles, native route geometry/durations, geocoder responses and provider
POI data do not form part of these ODbL files. This phase imports no proprietary
Yandex or 2GIS catalog. ODbL permission does not resolve the separate map-provider
agreement; the existing Phase B Yandex contract/geocoder/Open-in-Maps and public
deployment checks remain applicable. Native logos/copyright/links must remain
visible, and the actual account agreement must be reviewed before release.
