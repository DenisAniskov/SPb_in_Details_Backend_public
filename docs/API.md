# API

Базовый префикс API — `/api/v1`. Служебные endpoint'ы живут в корне: `/health`,
`/ready`, `/`. Ответы — JSON; интерактивная схема (`/docs`, `/redoc`,
`/openapi.json`) публикуется **только** при `BACKEND_ENV=development`.

Общие правила:

* Контракты строгие: неизвестные поля в теле запроса отклоняются, значения
  проверяются по границам (число points/legs, длины строк, диапазоны координат).
* Тело запроса — не более `REQUEST_MAX_BYTES` (по умолчанию 16 КиБ), строка
  параметров — не более `QUERY_MAX_BYTES`, чтение тела ограничено по времени.
* Внешние источники и модельные датасеты включаются оператором; при
  выключенном или отсутствующем источнике endpoint честно сообщает
  недоступность вместо синтетических чисел.
* Ошибки не раскрывают внутренние детали: `422` — «Некорректное значение
  параметра.», `503` — временная недоступность, `500` — «Внутренняя ошибка
  сервиса.». Ключи и текст запроса в ответах и логах не появляются.

## Служебные

| Метод и путь | Ответ |
| --- | --- |
| `GET /health` | `{"status": "ok", "service": ..., "version": ...}` |
| `GET /ready` | `{"status": "ready"}` или `503 {"status": "not_ready"}` |
| `GET /` | корень API, ссылки на `/health`, `/ready`, `/api/v1` |

Имя сервиса в `/health` сохраняет исторический внутренний идентификатор
`SmartNavigator SPb API` ради совместимости с уже выпущенным клиентом.

## Места

| Метод и путь | Назначение |
| --- | --- |
| `GET /api/v1/places/categories` | категории интересов с количеством мест |
| `GET /api/v1/places` | список мест: `category` (повторяемый), `is_unusual`, `q` (≤200 символов), `limit` (1–200, по умолчанию 100), `offset` |
| `GET /api/v1/places/{place_id}` | подробная карточка, `404` если места нет |
| `GET /api/v1/places/{place_id}/history` | историческая карточка по `catalog_key`; отсутствие карточки — это `history: null`, а не ошибка |

## Маршруты

| Метод и путь | Назначение |
| --- | --- |
| `POST /api/v1/routes/propose-walk` | детерминированный подбор прогулки по каталогу: пресеты, категории, бюджет времени. Ответ — предложение, которое клиент затем строит через MapKit |
| `POST /api/v1/routes/evaluate` | **не реализовано**: точка входа для будущей комплексной оценки сообщает об этом явно и требует, чтобы `destination_place_id` указывал на существующее место |

Правила подбора, ограничения и additive-поля описаны в
[PHASE_C2_LOCAL_ROUTING_ALGORITHM.md](PHASE_C2_LOCAL_ROUTING_ALGORITHM.md) и
[SMART_WALK_ALGORITHM.md](SMART_WALK_ALGORITHM.md); поля запроса и ответа —
`app/schemas/route.py`.

## Оценка существующего маршрута

Все четыре endpoint'а принимают один и тот же маршрут — список legs с геометрией — и **никогда не генерируют маршрут**. Момент времени обязателен для Shade, Puddle и Pollen (`departure_at`) и необязателен для Quiet (`assessed_at`, по умолчанию — текущее время UTC); указанное время обязано иметь явное UTC-смещение, naive-моменты отклоняются:

| Метод и путь | Что оценивается | Полный контракт |
| --- | --- | --- |
| `POST /api/v1/environment/shade/analyze` | тень по геометрии зданий и положению солнца | [PHASE_C7_1_API_CONTRACT.md](PHASE_C7_1_API_CONTRACT.md) |
| `POST /api/v1/environment/puddle/analyze` | риск мокрых участков по снимку дорог | [PHASE_C7_2_API.md](PHASE_C7_2_API.md) |
| `POST /api/v1/environment/pollen/analyze` | концентрации пыльцы CAMS (opt-in) | [PHASE_C7_3_API.md](PHASE_C7_3_API.md) |
| `POST /api/v1/environment/quiet/analyze` | относительный прокси дорожного шума | [PHASE_C11_API_CONTRACT.md](PHASE_C11_API_CONTRACT.md) |

Ответ каждого движка содержит оценку, происхождение данных и ограничения
модели; статус `unavailable` означает, что источник отключён или датасет
недоступен.

## Внешний поиск

Требуют серверных ключей Яндекса (`SUGGEST_API_KEY`, `GEOCODER_API_KEY`);
без них возвращается честная недоступность. Ключ никогда не покидает сервер.

| Метод и путь | Параметры |
| --- | --- |
| `GET /api/v1/search/suggest` | `text` (1–150), `results` (1–10, по умолчанию 7) |
| `GET /api/v1/search/geocode` | `text` (≤250) или `uri` (≤500, идентификатор из suggest) |
| `GET /api/v1/search/reverse-geocode` | `lat`, `lon` |

Поисковые запросы дополнительно ограничены анонимным лимитом по адресу
клиента и суточным бюджетом попыток (`YANDEX_*_DAILY_BUDGET`). При превышении
— `429` с `Retry-After`.

## ИИ-помощник

| Метод и путь | Назначение |
| --- | --- |
| `POST /api/v1/assistant/chat` | обычный ответ; режим (`guest_limited` / `private_test`) выбирает оператор |
| `POST /api/v1/assistant/chat/stream` | тот же помощник потоком SSE (`AI_ASSISTANT_STREAMING_ENABLED`) |
| `GET /api/v1/assistant/capabilities` | публичная информация о доступности помощника |
| `GET /api/v1/assistant/status` | операторский статус с токеном доступа |
| `GET /api/v1/assistant/backup/export` | разовая выгрузка проверенной резервной копии; скрыт из схемы и по умолчанию выключен |

Помощник работает только на free-моделях OpenRouter (`:free`), учитывает
попытки в durable-журнале, ограничен по частоте (на источник и глобально), по
длине сообщения/истории/ответа и по параллелизму. Ключ OpenRouter хранится
только на сервере; ошибки и SSE-события не содержат ключей и внутренних путей.

## Коды состояния

| Код | Когда |
| --- | --- |
| `400` | некорректный объявленный размер запроса |
| `404` | нет места с указанным `place_id` |
| `408` | истёк таймаут чтения тела |
| `413` / `414` | тело / строка параметров больше допустимого |
| `422` | не прошла валидация контракта |
| `429` | превышен лимит частоты или суточный бюджет (с `Retry-After`) |
| `503` | перегрузка сервиса, недоступность базы или защиты квоты, неготовность |
