## Данные

| Тип данных | Режим |
| --- | --- |
| Геоданные из OpenStreetMap (каталог, здания, дороги, scenic-набор) | ODbL 1.0, © OpenStreetMap contributors; см. [../app/db/README.md](../app/db/README.md) |
| Редакционные описания, исторические карточки, теги, оценки времени | оригинальные материалы проекта; разрешение на переиспользование вместе с каталогом и производными каталогами на условиях ODbL зафиксировано в [../app/db/README.md](../app/db/README.md) |
| Ответы Яндекса, тайлы и копирайты | не входят в ODbL-наборы и не могут в них добавляться |
| Модельные данные Open-Meteo/CAMS | условия поставщика; обязательна атрибуция, CAMS требует указания «Contains modified Copernicus Atmosphere Monitoring Service information» |

Данные ODbL нельзя объявлять собственностью проекта в режиме «все права
защищены»: лицензия кода и лицензия данных — разные вещи, и они не
смешиваются. Подробности происхождения — [DATA_AND_ATTRIBUTIONS.md](DATA_AND_ATTRIBUTIONS.md).

## Сторонние компоненты

Зависимости сохраняют свои лицензии (FastAPI, Starlette, Pydantic, SQLAlchemy,
Shapely, NumPy, httpx, uvicorn, aiosqlite, tzdata и другие — преимущественно
MIT/BSD/Apache-2.0). Точный набор закреплён в `requirements.runtime.lock`;
условия каждой библиотеки приведены в её собственном дистрибутиве. Тексты чужих
лицензий в этом репозитории не перепечатываются и не выдаются за лицензию
проекта.
