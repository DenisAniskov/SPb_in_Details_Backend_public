# Данные и атрибуция

Этот репозиторий публикует вместе с исходным кодом закреплённые снимки данных и
их происхождение, потому что значительная часть проверяемых утверждений проекта
опирается на них. Все геоданные происходят из
[OpenStreetMap](https://www.openstreetmap.org/copyright) и распространяются по
лицензии **[ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/)**:
**© OpenStreetMap contributors**.

Для Quiet Engine манифест `data/quiet_spb_pilot.manifest.json` дополнительно

файла: официальный вызов OSM API 0.6, SHA-256 запроса (`374d936b…62a1`) и ответа (`3016af9b…a084`), дата выгрузки и границы пилота.

Машиночитаемый источник каталога и его аудит:

* `docs/osm_source_snapshot.json` — выбранные OSM-объекты для каталога;
* `docs/phase_b_*`, `docs/phase_c2_*`, `docs/phase_c3_*`, `docs/phase_c6_1_*`,
  включая `*_acquisition/` с журналами запросов, манифестами и контрольными
  суммами, — поэтапная история расширения и проверки;
* `docs/phase_c7_1_acquisition/`, `docs/phase_c7_2_acquisition/`,
  `docs/phase_c7_3_acquisition/` — происхождение датасетов тени, дорог и проб
  источника пыльцы.

Сырые выгрузки OSM в `docs/phase_*_acquisition/` публикуются как есть, потому что они и есть источник происхождения датасетов. Они содержат имена участников OpenStreetMap и контактные теги объектов (включая адреса электронной почты и телефоны), которые уже опубликованы в самом OpenStreetMap под ODbL; проект не добавляет к ним новых персональных данных и не использует их для связи с людьми.

## Редакционные тексты

Описания, причины для посещения, предостережения, теги и оценки времени —
оригинальные редакционные материалы проекта, идентифицированные отдельно от
скопированных географических фактов. Проект разрешает копировать,
адаптировать, распространять и публично показывать их при переиспользовании
этого каталога или производных каталогов на условиях ODbL. Это разрешение не
перелицензирует код приложения, данные Яндекса, товарные знаки и сторонние
тексты или фотографии.

## Внешние службы

| Служба | Что используется | Условия и обязательства |
| --- | --- | --- |
| Яндекс (Suggest, Geocoder) | подсказки адресов, прямое и обратное геокодирование | официальные HTTPS endpoint'ы, серверные ключи оператора. Ответы Яндекса **не** входят в ODbL-наборы: их условия несовместимы с ODbL, и добавлять их в `data/` нельзя |
| Open-Meteo (погода) | модельная погода для оценки мокрых участков | включается явно (`PUDDLE_WEATHER_ENABLED`); бесплатный тариф некоммерческий, требуется атрибуция Open-Meteo |
| Open-Meteo Air Quality / CAMS | модельные концентрации пыльцы | включается явно (`POLLEN_SOURCE_ENABLED`); данные CAMS требуют указания «Contains modified Copernicus Atmosphere Monitoring Service information», бесплатный тариф некоммерческий |
| OpenRouter | free-модели ИИ-помощника | только модели с суффиксом `:free`; платный роутинг запрещён настройками, сбор данных по умолчанию запрещён (`AI_ASSISTANT_DATA_COLLECTION=deny`) |
| Geofabrik | PBF-выгрузка для снимка дорог Quiet Engine | источник зафиксирован манифестом (URL, дата, SHA-256); распространяемая производная база — сам gzip-набор выше |

Оператору следует повторно сверить условия этих служб перед коммерческой
эксплуатацией: репозиторий фиксирует только те ограничения, которые были
проверены на момент подготовки данных.

## Архивные ссылки

`docs/A5_EXTRACTION_MANIFEST.json` фиксирует происхождение кода — выделение из
монорепозитория `DenisAniskov/SmartNavigator_Spb` на ревизии `f09219ae`, а
также историю импорта файлов. Поля `source_repository` и
`destination_repository` в нём и URL в журналах acquisition (включая
историческое имя клиентского репозитория в User-Agent запросов) — **архивные**
ссылки на момент сбора данных, а не действующие адреса: клиент теперь
публикуется как
[SPb_in_Details_public](https://github.com/DenisAniskov/SPb_in_Details_public).
Журналы acquisition намеренно оставлены байт-в-байт: их контрольные суммы
подтверждают, что наборы собраны именно теми запросами.
