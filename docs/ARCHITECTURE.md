# Архитектура backend

Backend — один асинхронный процесс FastAPI, который отдаёт каталог
Санкт-Петербурга, подбирает прогулки по каталогу, оценивает существующие
маршруты модельными движками и проксирует ограниченный внешний поиск и
ИИ-помощника. Он не генерирует пешеходные маршруты и не заменяет MapKit:
маршрут всегда строит клиент, а backend только оценивает переданную геометрию.

## Слои

```text
HTTP → RequestLimitsMiddleware → router (/api/v1/...) → endpoint
     → service / engine (worker thread для GEOS) → SQLite или read-only датасет
     → upstream (Яндекс, Open-Meteo, OpenRouter) через ограничители
```

| Модуль | Ответственность |
| --- | --- |
| `app/main.py` | приложение, lifespan (backup → схема БД → сервисы), `/health`, `/ready`, обработчики ошибок |
| `app/api/v1/endpoints/` | тонкие HTTP-контракты: валидация Pydantic, коды ошибок, запуск сервиса |
| `app/core/config.py` | единая типизированная конфигурация с границами значений; ключи не попадают в `repr` |
| `app/core/request_limits.py` | лимит размера запроса/параметров, таймаут чтения тела, анонимный лимит поисковых запросов |
| `app/core/upstream_controls.py` | durable-учёт обращений к внешним API (скользящие 24 часа), серверный rate limit, семафор параллелизма |
| `app/core/logging_safety.py` | фильтр, который убирает из логов traceback и текст запроса |
| `app/db/session.py` | асинхронный движок SQLite, идемпотентная инициализация каталога по `catalog_key`, готовность |
| `app/db/seed_data.py`, `app/db/seed_places.json` | канонический каталог (180 записей) и его загрузка |
| `app/db/place_history.py`, `app/db/place_history.json` | 35 редакторских исторических карточек по `catalog_key` |
| `app/services/` | Smart Walk, Shade, Puddle, Pollen, Quiet, внешний поиск, ИИ-помощник |
| `app/schemas/` | строгие контракты ответов и запросов (дополнительные поля запрещены) |

## Движки

**Smart Walk** (`app/services/smart_walk_service.py`) — детерминированный
подбор прогулки по локальному проверенному каталогу: пресеты, категории,
бюджет времени, локальность и мягкое предпочтение «необычных» мест. Ответ —
предложение геометрии для клиента, а не пешеходный маршрут.

**Shade Engine C7.1** (`app/services/shade_engine/`) — геометрическая тень:
полигоны зданий из закреплённого SQLite-датасета (1409 зданий в шести зонах),
положение солнца на заданный момент, пересечение с сегментами существующего
маршрута. GEOS-работа (Shapely) выполняется в worker thread под
таймаутом и семафором. Высота здания берётся из OSM-тега, а при его отсутствии
оценивается по этажности; происхождение высоты возвращается в ответе.

**Puddle Engine C7.2** (`app/services/puddle_engine/`) — риск мокрых участков по
закреплённому снимку дорог (1094 way) и типам покрытия. Модельная погода
Open-Meteo — отдельный явный opt-in (`PUDDLE_WEATHER_ENABLED`), потому что
бесплатный тариф источника некоммерческий; вверх уходит только одна фиксированная
точка-центроид, никогда не геометрия пользователя.

**Pollen Engine C7.3** (`app/services/pollen_engine/`) — концентрации пыльцы
CAMS через Open-Meteo Air Quality. Источник выключен по умолчанию
(`POLLEN_SOURCE_ENABLED`), значение описывает одну ячейку 0.1° вокруг
фиксированного центроида, а не точку пользователя.

**Quiet Engine C11** (`app/services/quiet_engine/`) — относительный прокси
дорожного шума: ближайшая дорога в спроецированном STRtree и взвешенная по
длине оценка по закреплённому gzip-снимку (3638 way), целостность которого
проверяется по SHA-256-манифесту. Это не измерение в дБ и не акустическая
модель, проверенная в поле.

**Внешний поиск** (`app/services/yandex_search_service.py`) — подсказки и
прямое/обратное геокодирование официального HTTPS API Яндекса. Работает только
при заданных ключах; ключ остаётся на сервере, клиент его не получает.

**ИИ-помощник C13** (`app/services/assistant/`) — текстовый помощник на
free-моделях OpenRouter с контекстом из каталога, durable-квотами в той же
SQLite-базе, лимитами на сообщение, историю и вывод, а также SSE-потоком.
Платный роутинг запрещён конфигурацией (`AI_ASSISTANT_FREE_ONLY`), доступ
(`private_test` / `guest_limited`) выбирает оператор.

## Данные и хранилище

| Данные | Файл | Режим |
| --- | --- | --- |
| Каталог мест | `app/db/seed_places.json` → SQLite | синхронизация при старте по `catalog_key` |
| Исторические карточки | `app/db/place_history.json` | read-only, читается из файла |
| Здания для тени | `data/shade_buildings_spb_pilot.sqlite` | read-only, ODbL |
| Дороги для мокрых участков | `data/puddle_ways_spb_pilot.json` | read-only, ODbL |
| Дороги для Quiet | `data/quiet_spb_pilot.json.gz` + манифест SHA-256 | read-only, ODbL |
| Scenic-набор | `data/scenic_features.json` | read-only, 187 записей |
| Учёт внешних вызовов и квот ИИ | та же writable SQLite-база | транзакции `BEGIN IMMEDIATE` |

Записываемая база — только каталог, учёт обращений к внешним API и квоты
помощника. Все геопространственные датасеты неизменяемы и поставляются вместе с
исходниками и контрольными суммами, поэтому результат воспроизводим по
конкретным полученным байтам, а не по повторной выборке «сегодня».

## Жизненный цикл

1. `lifespan` создаёт при необходимости онлайн-резервную копию базы **до** любых
   изменений схемы (C13). Ошибка копии останавливает старт, а не портит базу.
2. `init_db()` идемпотентно добавляет отсутствующие места каталога по
   `catalog_key` и создаёт таблицы учёта квот.
3. Приложение объявляет себя готовым (`app.state.initialized`), `/ready`
   выполняет проверку базы с таймаутом `READINESS_TIMEOUT_SECONDS`.
4. Останов: закрытие сервиса помощника, затем внешнего поиска и движка SQLite.

## Ограничения и деградация

* `WORKERS` жёстко ограничен значением 1: каталог и квоты — один писатель.
* Каждый модельный движок имеет собственный семафор и таймаут; при отсутствии
  или отключении датасета endpoint честно сообщает `unavailable`, а не
  подставляет синтетику.
* `/routes/evaluate` — архитектурная точка входа, которая прямо сообщает, что
  комплексная оценка маршрута не реализована.
* Внешние источники (`pollen`, `quiet`, погода для мокрых участков, помощник)
  выключены по умолчанию и включаются оператором осознанно.
