## Честные ограничения

- Природа (95 объектов каталога) покрыта слабо (2 карточки): у большинства
  парков/скверов нет проверяемых первичных источников, достойных карточки;
  выдуманный «исторический контекст» запрещён §5.2.
- Памятники периферийных районов (капсулы локальной памяти) пока без
  расширенных карточек — требуется отдельная редакторская работа с
  районными источниками.
- По итогам итерации ревью (2026-10-11) каждая из 35 карточек опирается
  минимум на два источника: статья Википедии плюс независимый ресурс более
  высокого приоритета (официальный сайт музея/организации, государственный
  портал или научная публикация). Валидатор не выдаёт предупреждений об
  одноисточниковых карточках. Полный перечень доменов — в
  PHASE_C6_CONTENT_SOURCES.md; список источников каждой карточки печатает
  `python -m app.db.validate_place_history`.
- Присутствие старого `full_description` не приравнивается к расширенной
  карточке: аудит различает «описания каталога» и «проверенную историю».
