# Phase C6 — Редакторские правила

## Краткая историческая справка (§6.1)

- 2–4 предложения, отвечает на вопросы: что это, чем известно, почему стоит
  увидеть.
- Не дублирует название и адрес.
- Используется в трёх местах UI: карточка места («Краткая история»), строка
  остановки в предпросмотре Smart Walk, модальный шит «Краткая история» во
  время навигации.

## Подробная история (§6.2)

- Ориентир 150–250 слов; малый объект не растягивается (валидатор предупреждает
  при <80 и >320 слов, но не запрещает).
- Предпочтительный порядок: происхождение → основные этапы → архитектурные/
  культурные особенности → значение для города → что турист видит сегодня.
- Литературный русский язык, минимум терминов.

## Интересные факты (§6.3)

- 2–5 самостоятельных фактов на карточку; каждый факт имеет заголовок, текст
  и собственную ссылку на источник.
- Очевидные сведения (адрес, «красивое место») фактами не считаются.
- Неподтверждённые легенды фактами не оформляются.

## Хронология (§6.4)

- Показывается только при нескольких содержательных событиях.
- Даты хранятся с точностью (`exact/year/period/circa`); «середина XVIII века»
  никогда не превращается в конкретный год.
- Не выдумываются даты для заполнения интерфейса.

## Личности (§3.4)

- Только подтверждённые атрибуции с источником.
- Если авторство предмета споров — карточка пишет об этом прямо
  («архитектор достоверно неизвестен»).

## Статусы карточек

- `verified` — факты сверены с источниками, дата сверки указана. Все 35
  поставленных карточек имеют этот статус.
- `needs_review` / `draft` — допустимы схемой для будущей работы; валидатор
  предупреждает о таких карточках, чтобы они не приравнивались к проверенным.

## Запреты

- Не увеличивать формальное число карточек выдуманными фактами, шаблонными
  повторами или непроверенными датами.
- Не смешивать наличие старого `full_description` каталога с новой проверенной
  исторической карточкой: объект без расширенной карточки честно продолжает
  показывать существующие описания.
- Не выдумывать «исторический контекст» для современных или природных
  объектов; для них допускается история территории/учреждения только при
  проверяемых источниках (Новая Голландия, Севкабель Порт, Планетарий № 1).
